# Fairy Bucks printable sheets

Approved adult-fairy artwork, extracted from the owner's selected concept without redrawing it. Five single-page US Letter PDFs: four copies of each denomination (1, 2, 5, 10) and one mixed sheet. Notes are 6 inches wide, fronts only, with external dashed cutting guides. Print single-sided at 100% / Actual size. Parent Portal download links are generated after confirmed parent authentication and cleared on sign-out. The files themselves are static public print assets, not private records or spendable wallet credits. Printing never calls a balance mutation.

The supplied raster artwork is 1024 pixels wide; each note has about 165 effective pixels per printed inch at six inches wide. It is suitable for a home-print pilot but is not a vector or 300-dpi commercial press master. Colors and sharpness depend on the printer/paper; test one page before printing batches. No reverse side or duplex alignment is included.

`tools/build-fairy-bucks.py` composes the PDFs from the original approved 1024x1536 sheet. Requires Pillow, ReportLab and pypdf. No database migration is needed. The guide and FAQ nav uses disclosure panels without changing explorer routes.
